CONTINUOUS SCROLLING FIX

Sustained lag now reduces resolution from 1080p to 720p to 540p.
The viewer stays in animation mode at the smallest resolution.
Stills remain an explicit option and the reduced-motion default.
The controlled delay test observed each tier in order. At 540p, a failed
frame retained the previous picture and animation mode, then Retry
recovered the exact requested position.

The loader now accepts useful completed frames beyond the latest prefetch
window, while rejecting stale completions after direction or selection
changes. Displayed intermediate poses only advance toward the target.

Each sustained-scroll profile uses 100 native wheel events per direction,
80 ms apart, across the complete twelve-viewport scroll span. Frames are
not awaited between wheel events. All profiles use DPR 2 and a cold cache.

Profile                 Final tier   Forward updates   Reverse updates
Desktop, 1440 x 900      1080p        417               412
Throttled desktop       540p         69                98
Throttled phone         540p         78                107

Throttled profiles use 1.6 Mbps, 150 ms latency and 4x CPU slowdown.
The phone viewport is 390 x 844. Both throttled profiles lowered quality
twice. All profiles remained in animation mode, reached exact endpoints,
held stable after stopping and initially loaded only the active orientation.
Slow connections still skip intermediate poses while catching up.
These counts do not imply 30 fps playback.
